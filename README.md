#  Coffee Shop Sales Analysis Dashboard

A Python-based data analysis project that simulates coffee shop sales data, calculates key business metrics, and presents them in an interactive-style dashboard using data visualization libraries.

##  Project Overview

This project demonstrates a complete data analysis workflow by:

- Generating a realistic coffee shop sales dataset
- Cleaning and organizing data
- Calculating business KPIs
- Creating a professional dashboard to visualize sales performance

The project is designed to showcase data analysis and visualization skills using Python.

---

##  Key Performance Indicators (KPIs)

The dashboard includes:

-  Total Sales
-  Total Orders
-  Average Sale per Order
-  Total Profit

---

##  Dashboard Features

The dashboard provides visual insights into:

- Sales performance
- Profit analysis
- Customer distribution
- Product category performance
- Regional sales comparison
- Overall business metrics

---

##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
